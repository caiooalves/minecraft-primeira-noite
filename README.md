# Minecraft: sobrevivendo à primeira noite

Página desenvolvida para a atividade de HTML, com um guia básico para começar no modo sobrevivência do Minecraft.

O projeto usa apenas HTML, sem CSS ou JavaScript. Inclui estrutura semântica, listas, links, imagem com texto alternativo e ícone da aba.

## Como abrir

Abra o arquivo `index.html` no navegador. Mantenha a pasta `imagens` e o arquivo `favicon.ico` junto do HTML para que a imagem e o ícone apareçam.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `imagens/paisagem.png`: ilustração em blocos usada na página.
- `favicon.ico`: ícone da aba do navegador.
