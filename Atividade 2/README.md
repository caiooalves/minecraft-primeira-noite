# Minecraft — Primeira base

Atividade 2 de Desenvolvimento Web — Caio Alves Bezerra.

Página sobre como organizar uma base no Minecraft, com uma segunda página sobre exploração. O projeto usa HTML e CSS e continua o tema da atividade anterior.

Para abrir, baixe os arquivos e acesse `index.html` no navegador. O menu leva para `exploracao.html`. As duas páginas usam `style.css`.

A fonte Nunito vem do Google Fonts e precisa de internet para carregar. A imagem e o ícone ficam nos arquivos do projeto.
